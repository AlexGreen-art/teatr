# Teatr na Piętrze — strona demonstracyjna

Piąty przykład realizacji do portfolio. Miejsce, spektakle, ceny i osoby
są zmyślone.

## Problem, który ta strona rozwiązuje

Instytucja **grająca według kalendarza**. Klient nie pyta „ile kosztuje",
tylko „co i kiedy gracie i czy są jeszcze miejsca". Dlatego repertuar
jest tu najważniejszy i stoi zaraz pod nagłówkiem, a nie na podstronie.

To odróżnia projekt od czterech poprzednich: tam decydowała oferta,
tu decyduje data.

## Elementy charakterystyczne

**Repertuar z terminami i statusem miejsc** — data, tytuł, długość, cena
i informacja: wolne, ostatnie sztuki albo wyprzedane. Osiem terminów
mieści się na jednym ekranie.

**Najbliższy spektakl** wyróżniony zaraz pod nagłówkiem — bo to jedyna
rzecz, po którą wchodzi większość odwiedzających.

**Archiwum** — spektakle zdjęte z afisza z liczbą przedstawień. Buduje
wiarygodność mocniej niż jakikolwiek opis: 118 przedstawień to fakt.

## Pliki

```
index.html      cała strona
styl.css        arkusz stylów
skrypt.js       zastępniki brakujących zdjęć
img/            cztery zdjęcia — patrz BRIEF-ZDJEC.md
```
